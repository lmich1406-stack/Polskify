# Polskify 2.0 — Phase 1

Dodane:
- Profil użytkownika: avatar, nick, poziom, liga, województwa, seria, odznaki i statystyki.
- Top 100 z filtrem lig.
- Codzienne zadania.
- Daily reward: +20 monet raz dziennie.
- Monety + sklep z ramkami i avatarami.
- Statystyki: quizy, poprawne odpowiedzi, najlepszy wynik.
- Motyw jasny / ciemny.
- PWA: manifest + service worker + ikony instalacyjne.

## Instalacja
1. Supabase -> SQL Editor.
2. Wklej cały `POLSKIFY_2_PHASE1.sql` i kliknij Run.
3. Wrzuć cały folder jako nowy deploy na Netlify.
4. Wyloguj i zaloguj się ponownie.

## Kolejny etap
- tryb nauki,
- losowy quiz,
- osobne kategorie: stolice/rzeki/sąsiedzi/flagi/zabytki,
- lepszy ekran wyników,
- push notifications,
- Admin 2.0,
- anty-cheat 2.0,
- sezony z nagrodami.
