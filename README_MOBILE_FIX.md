# Mobile fix

Naprawiono problem, w którym na telefonie z jasnym motywem systemowym
tekst odpowiedzi quizu był prawie czarny na ciemnym tle.

Co zmieniono:
- ciemna paleta Polskify działa niezależnie od motywu telefonu,
- odpowiedzi i litery A/B/C/D mają wymuszony czytelny kontrast,
- przycisk „Mapa” jest czytelny,
- większe pola dotykowe na telefonie,
- lepsze odstępy i rozmiary tekstu,
- poprawione safe-area i przepełnienia.

Wgraj cały folder jako nowy deploy na Netlify.
