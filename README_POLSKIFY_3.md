Polskify 3.0
Dodano:
- Tryb nauki dla 16 województw.
- Losowy quiz z całej Polski.
- Quizy: stolice, rzeki, sąsiedzi, flagi, zabytki.
- Lepszy ekran wyników z animowanym wynikiem.
- Przypomnienia o serii (po zgodzie przeglądarki; gdy aplikacja jest otwarta).
- Admin 2.0: użytkownicy, ban/odban, XP, reset serii.
- Sezony miesięczne + punkty sezonowe.
- Specjalne quizy mają XP naliczane po stronie Supabase.
- PWA cache podbity.

Wymagane:
1. Uruchom POLSKIFY_3_SQL.sql w Supabase SQL Editor.
2. Wgraj folder na Netlify.
